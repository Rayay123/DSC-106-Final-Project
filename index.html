DSC 106 · Final Project

Two Climate Futures

Mapping the warming gap between a low and high-emissions world by 2100

Don Le · Raynard Taneka · Ethan Lam

What stands out

The scenarios do not separate evenly everywhere. By the end of the century, the gap between low and high emissions is especially large in some polar regions, while places closer to the equator generally show a smaller gap.

Prototype progress

What have we done so far?

We narrowed the project scope to focus on one question about how the warming gap changes/varies across locations. We then prepared the data for the prototype by converting the temperature, averaging yearly values, and calculates the warming since 2015-2024. This was done for the low, middle, and high emission scenarios. We then built the visualization using an interactive world map that has a tooltip, clickable location selection, markers for specific locations, and labels. We also added a legend, a dropdown for specific locations, and a line chart that updates based on which location is selected, allowing for closer examination over time. We supplemented the line plot with details about the change in temperature, type of scenario, and a comprehensive legend.

What will be the most challenging part to design, and why?

The most challenging part to design will be a comparison between two locations that the viewer can choose. This is difficult because using two comparison plots at the side would make the page cluttered and putting it at the bottom would make it difficult for the user to switch between the top and bottom visualizations. However a comparison on a single plot woudl also be difficult, as the existing line plot already has three scenario lines, a shaded gap, and reference lines. We also need to decide which details would make the comparison meaningful. Another challenge with the location comparison is how to show the two selections on the map, how to deselect one another, and how the line plot below will change along with the selection.

About the data

The prototype uses monthly CMIP6 projections from the NASA GISS-E2-1-G model. Warming is measured from the 2015–2024 average and summarized with a ten-year rolling mean. The results show one model run, so they do not represent the full range of uncertainty across all climate models.
